# pylite

A small interpreter, built from the ground up: lexer, parser and evaluator.

## A little poem

> The lexer reads each character in turn,
> and splits the text to tokens, one by one.
> The parser builds a tree from what they say,
> and the evaluator runs it till it's done.
>
> Through `while` and `func` the program finds its way,
> each scope a room the environment keeps.
> Out of plain text, the code begins to run:
> a tiny language waking from its sleep.
