ლექსი ძილზე

საღამო ფანჯარას ნელა ეხება,
ქუჩის შუქები თვალებს ხუჭავენ.
საბანი ჩუმად მხრებზე მეცვმება,
და დღე ბოლო ამოსუნთქვით მიდის.

ბალიში რბილად მიღებს თავს,
როგორც ძველი მეგობარი.
საათის ისრები ნელდებიან,
და ფიქრებიც ერთმანეთს ეთხოვებიან.

სიზმარი შორიდან მოდის ფეხაკრეფით,
მთვარის ბილიკზე მოდის და ჩერდება.
მე ვცურავ ღრუბლებში უწონად,
სადაც არც დრო არის და არც ჩქარობა.

დილამდე მშვიდად ვიძინებ,
სუნთქვა ტალღასავით მიდის და მოდის.
და როცა მზე კარზე დააკაკუნებს,
ძილი ნაზად გამომიშვებს ხელიდან.

ლექსი წყალზე

მთაში წვეთი პირველი იბადება,
კლდეზე ჩუმად ეცემა და მღერის.
ნაკადულად იქცევა ნელა,
და გზას ბალახებს შორის პოულობს.

მდინარე ქვებს ნაზად ეალერსება,
ყველა კიდეს თავის სახელს ამბობს.
მზე ზედ ვერცხლის ფერ ნახატს ხატავს,
და ტალღა ტალღას ეჯიბრება.

ზღვა ბოლოს ყველას ხვდება გულღიად,
ჰორიზონტს ცას უერთებს ჩუმად.
ქარი ზედაპირზე ლექსს წერს,
რომელსაც ნაპირი სწავლობს ზეპირად.

ღრუბლად ამოდის წყალი კვლავ ზეცად,
წვიმად ბრუნდება მიწას მადლობის სათქმელად.
და ასე წრე არასდროს წყდება,
რადგან სიცოცხლე წყალში იწყება.
